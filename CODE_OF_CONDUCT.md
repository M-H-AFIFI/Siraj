# Code of Conduct

Everyone participating in this repository (issues, pull requests, and discussions) is expected to keep conversations respectful and constructive.

## Expectations

- Be polite and patient, especially with first-time contributors and non-native English speakers.
- Focus feedback on the code and user experience rather than the person.
- Respect differing calculation methods, madhabs, and regional preferences supported by the app.

## Unacceptable behavior

Harassment, personal attacks, hate speech, trolling, or sharing private user information will not be tolerated. Maintainers may remove comments or restrict repository access for violations.

To report an issue privately, contact the repository maintainer through GitHub (`@M-H-AFIFI`).
