# Code of Conduct

Keep conversations in issues and pull requests respectful and constructive.

- Be patient with first-time contributors and people writing in a second language.
- Keep feedback focused on the code and app behavior.
- Respect differing calculation methods and regional preferences supported by the app.

Harassment, personal attacks, hate speech, or sharing private information will result in comments being removed or access restricted.

To report something privately, contact `@M-H-AFIFI` on GitHub.
